# Audience map geometry

Generated by `bun scripts/generate-audience-maps.mjs`. No runtime geography dependency or external map request.

- US: us-atlas 3.0.1, Census-derived states-albers-10m (Albers USA with Alaska/Hawaii insets).
- World: world-atlas 2.0.2, Natural Earth 4.1.0 countries-110m, Natural Earth projection.
- ISO country codes: i18n-iso-countries numeric-to-alpha2 conversion.

Atlas distributions use the ISC license reproduced in LICENSE. Country outlines are small-scale and may omit small territories; targeting chips retain the saved details. This display does not modify targeting or resolve provider-specific geography IDs.
